# My Hero Academia Open-World RPG — Production Plan

Fan project. Not for sale. Design references: Bailey's two design PDFs ("Architectural and Design Specification for a Systems-Driven My Hero Academia RPG" and "My Hero Academia: Open-World RPG Design Concept").

## The 8 stages (Bailey's plan)

1. **Idea** — What the game is, in one sentence. Who plays it.
2. **Pre-production** — Plan it. Write down the design, pick the engine, figure out how long it takes and who does what.
3. **Prototype** — Build the core thing rough and test if it's fun. Blockout / greybox: lay out the level with simple block shapes to test how it plays, before spending time on real art.
4. **Vertical slice** — One small piece of the game, finished to full quality. Proves the game can look and play the way Bailey wants.
5. **Production** — Build all of it. Real art, all the levels, all the features, code, sound. The longest part.
6. **Alpha** — All features are in, but buggy and some art still rough. No new features after this.
7. **Beta** — Everything is in. Only bug fixing and polish.
8. **Gold and launch** — The final build ships. Then patches and updates.

**Blockout rule:** blockout is only for testing inside the team. Bailey's rule still stands — no blocky shapes in anything Bailey sees.

## Where we are

- Stage: **1 → 2** (Idea done in the PDFs; Pre-production starting).
- Open decision for Bailey: **engine** — Unreal Engine 5 (what the PDF asks for; runs on Bailey's PC) or Godot (matches the Godot tools already collected).

## Stage 1 — Idea (draft, needs Bailey's yes)

A Skyrim-style open-world action RPG in a superhero Japan, where you create your own hero, pick a Quirk with a real body cost, and choose to be a Hero student, a Villain, or a Vigilante.
