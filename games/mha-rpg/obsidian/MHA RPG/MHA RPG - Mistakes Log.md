# Mistakes Log

Check this before similar work.

- **Hand v1 looked like tubes.** Built from smoothed capsules. Rule: no toy shapes; check realism before showing.
- **Body v1–v3 looked like stacked balloons / beads.** Rule: judge against the reference photo every round.
- **Waist over-pinched (v6).** Caught by tests. Rule: test proportions with real cross-sections.
- **Measuring bug:** rays at shoulder height ran into the arms. Rule: verify the test before trusting it.
- **Underwear v1 blocky with gaps.** Rule: never show placeholder-quality clothing; Checker + render first.
- **Glove was 1.1M triangles.** Rule: check triangle budgets every pass.
