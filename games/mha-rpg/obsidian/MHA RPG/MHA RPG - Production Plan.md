# Production Plan

1. **Idea** — what the game is in one sentence; who plays it. *(draft written, needs Bailey's yes)*
2. **Pre-production** — design, engine, timeline, who does what. **← we are here**
3. **Prototype** — rough core loop, greybox blocks to test fun. *Blocks are team-only; Bailey never sees blocky shapes.*
4. **Vertical slice** — one small piece at full quality.
5. **Production** — build all of it.
6. **Alpha** — all features in, buggy. No new features after.
7. **Beta** — bug fixing and polish only.
8. **Gold and launch** — final build, then patches.
